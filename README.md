# Insight Forge

Hybrid search and KPI dashboard monorepo scaffold.

## Quick Start

```bash
bash up.sh
```

The script creates a Python virtual environment, installs dependencies, downloads a small Wikipedia sample when needed, builds placeholder index artifacts, and starts:

- Backend: http://localhost:8000
- Frontend: http://localhost:5173

Stop both services with `Ctrl+C` from `up.sh`, or run:

```bash
bash down.sh
```
